# GoreeCloud Swarm — Branding

## Product identity

- **Canonical product name:** GoreeCloud Swarm
- **Short in-product name:** Swarm
- **Repository:** `GoreeCloud/goreecloud-swarm`

Swarm must use original GoreeCloud product identity. It must not copy or imitate qBittorrent, µTorrent, Transmission, Deluge, BitTorrent, or other client branding.

## Visual direction

Future artwork may explore connected nodes, distributed pieces, coordinated flows, peer clusters, or converging data streams. The icon must not imitate the traditional BitTorrent logo.

The application interface is intended to use the applicable current Glaze UI system. Glaze UI implementation is not present in this service foundation and must not be represented as complete.

Final application iconography, logos, launch artwork, store assets, and complete visual implementation have not yet been approved or implemented in this repository.
